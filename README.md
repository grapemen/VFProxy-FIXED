# VFProxy
 A PHP wrapper of the new VoiceForge API, which automatically converts it to MP3 using LAME for compatibility with the LVM.

## How to use
First, run the start.bat. Then, select the port you want to add. After that, go to your browser and type "http://localhost:(the port you selected)/vfproxy/speech.php?voice=(voice name, you can find them in voicelist.txt)&text(the text you want)". Finally, you finished!
## Adding it in Wrapper: Offline 1.2.3
First, copy the speech.php file in the vfproxy folder inside of the VFProxy fixed folder. Then, paste it into (wrapper offline 1.2.3 name)/wrapper/vfproxy/vfproxy. After that, test the voiceforge voices to see if they work. Finally, you got them working!
